## What it does

`main.ts` writes one number — my honest count of open browser tabs — to `/output/entry.txt`. Digits only, nothing else.

## The number

**417** — a real tab-hoarder count: high enough to surprise, odd and specific enough to believe, and it hints at a life of research, projects and articles left open, never quite closed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt  # 417
```

Pure Node.js, zero dependencies.
